# LiteGlow — лёгкий шейдерпак для Iris

Minecraft 1.21.x (проверялось под 1.21.11) · Fabric + Iris · OpenGL 3.3+

**Установка:** положите `LiteGlow.zip` в папку `shaderpacks` и выберите в Options → Video Settings → Shader Packs.

## Что внутри (и почему быстро)
- Нет теневой карты, нет SSAO/SSR, нет отложенных проходов: всё освещение считается в самих gbuffers-шейдерах (forward), плюс один финальный fullscreen-проход.
- HDR-буфер `R11F_G11F_B10F` (вдвое меньше трафика, чем RGBA16F).
- Освещение: цветное небесное + солнечное/лунное направленное, тёплый свет факелов, «фейковые» тени по уровню небесного света, ванильное AO.
- Процедурное небо: градиент, рассвет/закат, гало солнца, звёзды, дождливое небо; туман совпадает с цветом горизонта.
- Вода: анимированные нормали, отражение неба (Френель), блик солнца/луны.
- Колышущиеся трава, цветы, листва (вершинный шейдер).
- Тонмаппинг ACES, насыщенность/контраст/тёплота, виньетка, дизеринг против бандинга.
- Поддержка Нижнего мира и Энда (своя гамма и туман), подводного и лавового тумана.
- Настройки в меню и профили Lite / Default / Cinematic.
