# Adaptive View (Fabric, 1.21.11, loader ≥ 0.19.5, клиентский мод)

Автоматически меняет дальность прорисовки (render distance) по ситуации. Ваше значение в настройках — «базовое»;
мод добавляет/убирает чанки относительно него и возвращает базовое при выходе из мира / из игры.

| Ситуация | По умолчанию |
|---|---|
| Полёт на элитрах | +4 чанка (штрафы леса и гор при полёте не действуют) |
| Лес / джунгли / тайга / густая листва | −3 |
| Горы / холмы | −3 |
| Вы ударили сущность (только ваши удары) | −4 на 8 секунд |
| Низкий FPS (выключено по умолчанию) | −2 при FPS < 30 |

Ограничения `min`/`max`, задержки до повышения/понижения, размер и интервал шага настраиваются.

**Настройки:** Параметры → Настройки видео (Sodium 0.8.x) → вкладка **Adaptive View** (как у Iris).
Без Sodium конфиг лежит в `config/adaptive_view.json`.

Если вы меняете ползунок дальности вручную, мод принимает это как новое базовое значение.
В мультиплеере дальность ограничена сервером (выше его лимита не станет).

Сборка: Gradle 9.4+, `gradle build` (Loom 1.16). Нужен Sodium 0.8.14 как compile-зависимость (подтягивается из Modrinth Maven).
