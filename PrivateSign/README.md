# Private Sign (Fabric 1.21.11, Loader ≥ 0.19.5, Fabric API)

Любая табличка, которую ставит игрок (обычная, настенная, висячая, любой вид дерева), сразу получает текст:

```
Частная 
территория
 Сунгирь
```
(пробелы в конце 1-й строки и в начале 3-й сохраняются — это и есть отступы.)

- Работает на сервере (клиентам мод ставить не нужно); в одиночной игре тоже.
- Конфиг `config/private_sign.json` (UTF-8), создаётся при первом запуске:
  - `lines` — 4 строки таблички (пробелы по краям сохраняются);
  - `skipEditor` (по умолчанию `true`) — не открывать редактор текста после установки; `false` — текст подставлен, но игрок может его поправить;
  - `wax` (по умолчанию `false`) — запечатать табличку воском, чтобы текст нельзя было изменить;
  - `backSide` — писать тот же текст и на обратной стороне.
- Установка: `dist/private-sign-1.0.0.jar` в `mods/` сервера (+ Fabric API).
