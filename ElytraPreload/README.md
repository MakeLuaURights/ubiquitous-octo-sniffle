# Elytra Preload (Fabric, 1.21.11, loader ≥ 0.19.5)

Заранее загружает/генерирует чанки по ходу полёта игрока (элитры, быстрый полёт, лодка и т.п.),
чтобы не было фризов от генерации чанков на лету.

- **Singleplayer:** просто положить jar в `mods/` (нужен Fabric API).
- **Multiplayer:** работает на стороне сервера. Поставьте jar на сервер — клиентам мод не нужен.
  Мод на одном клиенте не может заставить чужой сервер грузить чанки.
- Конфиг: `config/elytra_preload.properties` (создаётся при первом запуске).
  На слабых устройствах уменьшите `lookaheadSeconds`, `maxExtraChunks`, `lateralWidth`.
- Сборка: `gradle build` → `build/libs/`.
